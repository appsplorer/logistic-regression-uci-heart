# Heart Disease Prediction using Logistic Regression

## Overview
This project implements a **Logistic Regression** model to predict the presence of heart disease using the **UCI Heart Disease dataset**. The project covers **data preprocessing, model training, evaluation, and result visualization**.

## Dataset
- Source: [UCI Heart Disease Dataset](https://www.kaggle.com/ronitf/heart-disease-uci)
- Features include age, sex, chest pain type, blood pressure, cholesterol, and more.
- Target: `target` (0 = no heart disease, 1 = heart disease)
